# 图注 VLM 描述：含义与 MVP 取舍

## 是什么

MinerU 解析 PDF 时会抽出图片/表格的截图，并尽量识别图注文字。但很多教材插图只有图形、没有可读文字说明。**图注 VLM 描述**是在解析完成后，把每张图片再发送给一个支持图片输入的大模型（Vision-Language Model），让它生成一句自然语言说明，例如：

> 图 3-2：三层神经网络结构，左侧为输入层，中间为隐藏层，右侧为输出层；箭头表示前向传播方向。

生成的描述可以附加到图片块上，用于全文检索、问答引用和图片的可访问性说明。

## 代价

- 需要额外的视觉模型端点与 API Key（与 MinerU token 不同）；
- 每张图都要外发一次图片，涉及隐私与费用；
- 增加解析耗时、失败重试与结果缓存设计；
- 输出质量取决于模型，描述可能误导，需要在 UI 中标注来源。

## MVP 决策

按最小范围执行：

1. 设置中保留一个 **默认关闭** 的「图注 VLM 描述（预留）」开关；
2. MVP **不实现**图片外发与描述生成；开关打开时明确提示当前版本不启用，而不是静默忽略；
3. 关闭状态下，除用户主动触发的 MinerU 解析与结果 zip 下载外，不产生任何外发请求；
4. 未来若启用，将接入可配置的 OpenAI 兼容视觉端点，并用独立的请求 allowlist/计数测试保证关闭时零外发。

验收第 5 条按此语义执行：**关闭图注时没有额外的图片/VLM 请求**；MinerU 解析本身不属于图注请求。

## 测试计划

- 用可注入的 fetch 计数器跑一次完整解析流程，断言所有请求 host 均在允许集合内；
- 断言没有 `/chat/completions`、`/embeddings`、`/images` 等图注/VLM 请求；
- 图注开关关闭时，即使解析产物包含图片，也只保存图片，不读取图片内容外发；
- 开关打开（预留）时返回明确的「当前版本未实现」错误，不发请求。
